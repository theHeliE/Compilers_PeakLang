## 📖 Overview

**PeakLang** is a custom programming language designed to explore modern language features and compiler construction paradigms. This repository contains the complete compiler toolchain built from scratch, transforming PeakLang source code into optimized executable formats.

## ⚙️ Compiler Pipeline

The PeakLang compiler architecture relies on a classic multi-phase pipeline:

1. **Lexical Analysis (Scanner)**: Tokenizes raw source strings into a structured stream.
2. **Syntax Analysis (Parser)**: Constructs an Abstract Syntax Tree (AST) using recursive descent/table-driven parsing.
3. **Semantic Analysis**: Enforces static typing, resolves scopes, and validates memory bindings.
4. **Intermediate Representation (IR)**: Lowers the AST into a structured IR for optimizations.
5. **Code Generation**: Emits the final target representation (e.g., Assembly, LLVM IR, or Bytecode).

## 🛠️ Prerequisites

To build the PeakLang compiler, ensure your development environment has the following installed:

* A **C++17** compatible compiler (`gcc`, `clang`, or `msvc`)
* **CMake** (v3.10 or newer)
* *Optional: Flex/Bison or LLVM libraries depending on implementation details*

## 🚀 Building from Source

We use CMake to ensure cross-platform build compatibility. 

```bash
# 1. Clone the repository
git clone https://github.com/theHeliE/Compilers_PeakLang.git
cd Compilers_PeakLang

# 2. Create a build directory
mkdir build && cd build

# 3. Configure and compile
cmake ..
cmake --build .
```

## 💻 Usage

Once successfully compiled, you can run the `peakc` executable to compile your PeakLang scripts.

```bash
./peakc [options] <input_file.peak> -o <output_file>
```

**Helpful Compiler Flags:**
| Flag | Description |
| :--- | :--- |
| `-h`, `--help` | Display usage information and available commands |
| `--dump-ast` | Print the Abstract Syntax Tree to `stdout` for debugging |
| `--tokens` | Output the raw token stream generated by the lexer |
| `-O<level>` | Set optimization level (e.g., `-O1`, `-O2`, `-O3`) |
